# Architecture Diagrams

C4 (context/container/component) and sequence diagrams for the
Orchestrator. Text-form versions of the C4 Level 1-3 diagrams already
exist in `docs/architecture.md` §2 — this folder is for rendered
diagram source files (e.g., `.drawio`, `.mmd` Mermaid sources, or
exported images) once the design stabilizes past the draft stage.
